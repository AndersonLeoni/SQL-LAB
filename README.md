# SQL-LAB

Laboratório pessoal de estudos de SQL e bancos de dados. Esta página transforma as anotações em uma wiki de consulta, com uma trilha completa de PL/SQL para Oracle, do primeiro bloco a recursos avançados.

## Abrir a wiki

Abra `index.html` no navegador ou publique o repositório com GitHub Pages (Settings → Pages → Deploy from a branch → `main` / `/ (root)`). A interface é estática: não precisa de build, conta ou servidor de aplicação.

## Trilha PL/SQL para Oracle

Os guias seguem a progressão temática do livro *PL/SQL: Domine a linguagem do banco de dados Oracle*, de Eduardo Gonçalves. Os textos e exemplos do LAB são sínteses e exercícios próprios; para explicações completas, consulte o livro.

1. **Fundamentos** — PL/SQL, blocos, ambiente, `DBMS_OUTPUT`, variáveis, tipos e transações.
2. **Construção de programas** — SQL em blocos, condições, funções SQL, laços, cursores e exceções.
3. **Recursos avançados** — procedures, functions, packages, transações autônomas, triggers, collections, records, `UTL_FILE` e SQL dinâmico.

Cada guia mostra o nível, o capítulo relacionado, objetivos, conceitos, um exemplo e um exercício curto. Use a busca ou a navegação lateral para consultar os tópicos.

## Conteúdo que já existia

As anotações originais seguem nas pastas `primeiros-passos-sql/`, `Manipulando Dados/`, `Manipulando o BD com comandos da DDL/`, `Modelando dados com SQL Server/`, `SQL SERVER - Constraints, Funções e Procedures/`, `formacao-sql-db-specialist/` e `Projetos/`. O conteúdo de SQL Server está separado da nova trilha Oracle porque os dialetos e recursos não são intercambiáveis.

## Referência bibliográfica

GONÇALVES, Eduardo. *PL/SQL: Domine a linguagem do banco de dados Oracle*. Casa do Código. Sumário e tópicos consultados para organizar a trilha: capítulos 1–24.

> Os comandos foram escritos para Oracle Database. Ajustes podem ser necessários conforme a versão do banco, privilégios e ferramenta SQL utilizada.

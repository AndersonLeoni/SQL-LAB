# 📊 Performance Dashboard

Um dashboard desenvolvido para consolidar, analisar e visualizar indicadores de desempenho de forma simples, intuitiva e eficiente.

O objetivo do projeto é transformar dados em informações úteis para apoiar a tomada de decisão, utilizando boas práticas de desenvolvimento, organização de código e visualização de dados.

---

## 🚀 Objetivos

- Centralizar indicadores de desempenho.
- Criar dashboards claros e intuitivos.
- Automatizar a atualização dos dados.
- Facilitar análises através de gráficos e métricas.
- Servir como projeto de estudo e portfólio.
